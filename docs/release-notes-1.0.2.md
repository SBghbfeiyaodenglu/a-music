# A-Music 1.0.2

这是一个**小修复版本**，功能和 1.0.1 一样，只修了搜索结果播放相关的问题。

## 修了什么

**从搜索结果播放另一个列表里的同名歌曲后，歌放完会出现列表和歌词空白、进度条不动。**

原因有两个：

- 搜索结果只记住了歌、没记住它属于哪个列表；同名歌曲在多个列表里时，可能播到另一个列表的版本；
- 播放器自动换到下一首后，如果界面没跟上，界面会停在“没有当前歌曲”的状态，但播放器还在继续放。

现在：

- 点搜索结果里的哪一行，就按那一行**自己的列表**播放；
- 播放器换歌后界面会自动找回它所在的列表，列表、歌词和进度条跟着恢复；
- 正常播放时这套恢复逻辑不会做任何事，也不会把正在浏览的列表强行切走。

## 下载与安装

下载 `A-Music-1.0.2.apk`，在手机上点击安装（需允许“安装未知来源应用”）。
已经装过 1.0 / 1.0.1 的可以直接覆盖安装，列表、设置和播放进度都不会丢。

## 说明

- 支持 Android 7.0（API 24）及以上
- 纯本地播放，不采集数据、没有账号和广告；唯一联网用途是你主动点「在线搜词」
- 不支持各种歌单（音乐平台歌单、`.m3u` / `.pls` 文件都不能导入）
- 其余功能说明见 1.0.1 和 1.0 的发布说明
