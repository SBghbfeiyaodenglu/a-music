# A-Music 1.0

一个**纯本地**的 Android 音乐播放器：只读你自己手机里的音频和歌词，
不采集任何数据、没有账号和广告；**唯一需要联网的是「在线搜词」**，你主动点它才联网。

**不支持各种歌单**：音乐平台的歌单、`.m3u` / `.pls` 这类歌单文件都不能导入，
歌只能从你自己手机里的音频文件导入（导入后可以在应用里自己建列表）。

## 下载与安装

下载 `A-Music-1.0.apk`，在手机上点击安装（需允许"安装未知来源应用"）。
已经装过旧版本的可以直接覆盖安装，列表和设置都不会丢。

装好后按提示授权：

- **音乐和音频** —— 读取音频文件
- **所有文件访问权限** —— 读取音频旁边的同名 `.lrc` 歌词文件（原因见下）
- **通知** —— 媒体通知与锁屏控制（首次播放时申请）

> **为什么需要"所有文件访问"？**
> Android 11 起 `.lrc` 属于非媒体文件，用路径读不到、媒体库也查不到，
> 而"同名 LRC 优先"是本应用最核心的规则。本应用只用它读取音频和同名歌词：
> 不写入、不上传、不删除你的任何文件；唯一的写入场景是你主动使用"歌词偏移"
> （改写该歌曲的 `.lrc` / 内嵌歌词，并先备份原文件）。
> 因为这个权限，它无法上架 Google Play，只能这样侧载分发。

## 主要功能

- **歌曲与列表**：目录浏览导入、多列表、重复导入检测、显示字段可选、全局搜索、
  长按多选批量移出列表、删除列表需确认（"删除所有列表"为两道确认）
- **播放**：后台播放 + 媒体通知 + 锁屏控制；五种播放模式（顺序 / 倒序 / 随机 / 单曲 / 跨列表循环）；
  旋转、切列表、锁屏都不中断播放；睡眠定时器（10~90 分钟，到点暂停，重启后倒计时依然准）
- **歌词**：同名 `.lrc` → 内嵌歌词 → 无；支持一行多时间标签、多种毫秒写法、`[offset:±毫秒]` 偏移标签；
  自动滚动提前 0.5 秒；长句换行不截断；歌词偏移可调并同时改写 `.lrc` 与内嵌歌词；7 档字号
- **外观**：可选把专辑封面重度模糊成柔和的明暗色调当背景（默认关闭）；
  打开后背景明显可见，同时文字对比度仍有保证（浅灰正文 7~9:1，要求 4.5:1）

## 说明

- 支持 Android 7.0（API 24）及以上
- 安装包已启用代码混淆与资源压缩（约 2.8 MB）
- 没有均衡器 / ReplayGain / Android Auto / 桌面歌词 / 双语歌词
- 本应用不提供、不下载、不搜索任何在线音乐内容，播放的是你自己设备上的文件
