# A-Music 1.2.2

这是一个**小修复版本**，修复同一首歌在列表里出现两个同名条目的问题。

## 改了什么

Android 上下面这些路径其实指向同一个位置：

- `/sdcard/...`
- `/storage/self/primary/...`
- `/mnt/sdcard/...`
- `/storage/emulated/0/...`

如果列表里一条记录用的是别名路径、另一条用的是标准路径，文件夹同步会把它们当成两首歌，结果就是同一个音频文件在列表/搜索里出现两次。

现在：

- 所有路径比较都先统一换算成 `/storage/emulated/0/...`；
- 文件夹同步时按归一化后的路径去重：同一首歌只保留一条记录；
- 优先保留与当前文件夹扫描路径写法一致的那条；
- 只删除列表里的重复引用，不会删除、移动或改写任何音频/歌词文件，也不影响其它列表。

升级后第一次同步会自动清掉已有的别名重复记录。

## 下载与安装

下载 `A-Music-1.2.2.apk`，在手机/平板上点击安装（需允许“安装未知来源应用”）。
已经装过旧版本的可以直接覆盖安装，列表、设置和播放进度都不会丢。

## 说明

- 支持 Android 7.0（API 24）及以上
- 纯本地播放，不采集数据、没有账号和广告；唯一联网用途是你主动点「在线搜词」
- 不支持各种歌单（音乐平台歌单、`.m3u` / `.pls` 文件都不能导入）
- 上一个版本 1.2.1 已支持播放中实时发现新增/替换的同名 `.lrc`
- 其余功能说明见 1.2.1 / 1.2 / 1.1.2 / 1.1.1 / 1.1 / 1.0.3 / 1.0.2 / 1.0.1 / 1.0 的发布说明
