# A-Music 1.1.2

这是一个**小修复版本**，只调整搜索弹窗的文案和配色，功能不变。

## 改了什么

搜索弹窗的两个结果分区改成更直白的名字，并用不同颜色区分：

- 上方 **「列表搜索结果」** —— 橙色：已经导入到列表里的歌；
- 下方 **「全文件搜索结果」** —— 蓝色：手机/平板存储里扫描到的音频文件。

状态行也同步改为「列表结果 N 首 / 全文件结果 M 个」，占位提示、无权限提示、
空结果提示统一改成“列表 / 手机/平板全文件”的说法。

搜索、播放、导入的逻辑完全不变。

## 下载与安装

下载 `A-Music-1.1.2.apk`，在手机上点击安装（需允许“安装未知来源应用”）。
已经装过旧版本的可以直接覆盖安装，列表、设置和播放进度都不会丢。

## 说明

- 支持 Android 7.0（API 24）及以上
- 纯本地播放，不采集数据、没有账号和广告；唯一联网用途是你主动点「在线搜词」
- 不支持各种歌单（音乐平台歌单、`.m3u` / `.pls` 文件都不能导入）
- 其余功能说明见 1.1.1 / 1.1 / 1.0.3 / 1.0.2 / 1.0.1 / 1.0 的发布说明
