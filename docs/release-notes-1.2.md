# A-Music 1.2

这是一个**功能更新**：列表现在会自动跟随它对应的实际文件夹。

## 列表跟着文件夹走

以前导入完，文件夹里后来加的歌、删掉的文件，列表都不会变，得手动再导一次。
现在只要列表是在导入时**勾选文件夹**导入的，它就会记住这些文件夹，并自动保持同步：

- 往文件夹里**新增**音频 → 回到应用约 10 秒内自动出现在列表里；
- 从文件夹里**删除/移走**音频 → 列表里对应的那一条自动消失；
- 文件换了标签、体积或修改时间变了 → 列表里的歌手等信息跟着刷新。

同步只改列表里的记录，**不会删除、移动或改写任何音频文件和歌词文件**。

## 几个细节

- **怎么绑定**：导入时勾文件夹左侧的复选框，或者进到目录里点「全选本层」整目录导入，
  这个列表就和这些文件夹绑定了；以后往同一个列表再勾别的文件夹导入，会继续累加。
  只挑单曲导入的列表不绑定。
- **老列表**：升级后第一次同步时，只有当列表里的歌和某个文件夹里的音频**完全一致**
  （不多不少）才自动绑定该文件夹；精挑的子集、分散在多个目录、搜索临时列表都不猜，
  保持原样（想让它跟随，重新勾这个文件夹导入一次即可）。
- **手动删掉的歌不会被加回来**：从列表里手动移除或清空的歌会记住，
  就算文件还在文件夹里，同步也不会把它捡回来。
- **读不到文件夹时不会乱删**：存储卡没挂载、没权限时会跳过这一轮，一条都不删。
- 同步在应用回到前台后每 10 秒检查一次；打开弹窗、搜索、导入、多选操作时暂停，
  不会在你操作列表时从下面自己增删。

列表、设置、播放进度都不受影响；升级可直接覆盖安装。

## 下载与安装

下载 `A-Music-1.2.apk`，在手机上点击安装（需允许“安装未知来源应用”）。
已经装过旧版本的可以直接覆盖安装。

## 说明

- 支持 Android 7.0（API 24）及以上
- 纯本地播放，不采集数据、没有账号和广告；唯一联网用途是你主动点「在线搜词」
- 不支持各种歌单（音乐平台歌单、`.m3u` / `.pls` 文件都不能导入）
- 其余功能说明见 1.1.2 / 1.1.1 / 1.1 / 1.0.3 / 1.0.2 / 1.0.1 / 1.0 的发布说明
