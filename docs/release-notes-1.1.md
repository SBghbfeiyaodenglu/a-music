# A-Music 1.1

这次主要是**平板/大屏适配**，以及**没建列表也能直接搜歌播放**。

## 歌词字号更大

歌词字号从 7 档扩到 **12 档（24~56sp）**：

- 前 7 档的数值完全不变，老用户原来的字号看起来一样；
- 新增 5 档更大的字号（40 / 44 / 48 / 52 / 56sp），平板上可以调得更大；
- 歌词仍然是一行一句、纵向滚动，没有改成横向并排。

## 平板/大屏排版

宽度 ≥ 600dp 的设备（平板、横屏）会自动利用横向空间：

- **歌曲列表**：序号和歌名之间留出空隙，左右留白也加大，不再贴着序号；
- **导入页**：文件名、歌手、「有 LRC / 有内嵌」从上下两行改成同一行；
- **搜索结果**：歌名和「歌手 / 所在列表 / 文件大小」改成同一行。

手机窄屏维持原来的布局。

## 没列表也能直接搜歌播放

- 没有列表时，在搜索里点一首本地歌曲：自动新建「临时列表」→ 导入 → **直接播放并进入歌词页**，
  不再提示“请先选择一个列表”；
- 有列表时，搜索结果的「+」也改成**导入并播放**（以前只导入）。

## 下载与安装

下载 `A-Music-1.1.apk`，在手机上点击安装（需允许“安装未知来源应用”）。
已经装过旧版本的可以直接覆盖安装，列表、设置和播放进度都不会丢。

## 说明

- 支持 Android 7.0（API 24）及以上
- 纯本地播放，不采集数据、没有账号和广告；唯一联网用途是你主动点「在线搜词」
- 不支持各种歌单（音乐平台歌单、`.m3u` / `.pls` 文件都不能导入）
- 包含 1.0.3 的修复：目录导入未进媒体库的文件，时长不再显示 0:00
