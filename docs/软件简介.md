# A-Music · 纯粹的安卓本地音乐播放器，无广告无弹窗

**播放**：支持多种格式的歌曲播放 —— MP3 / FLAC / M4A / AAC / OGG / OPUS / WAV / WMA / APE / AIFF / MKA

**歌词**：支持歌曲内嵌歌词和同名 LRC 歌词文件（LRC 歌词文件需和歌曲在同一目录）；支持在线搜词、偏移校正、直接编辑、7 档字号调整

**弱联网**：唯一需要联网的是「在线搜词」，其余功能全部可离线使用

**搜词说明**：本工具的在线搜索歌词依赖于网络，可能有时候无法搜索到想要的歌词，这属于正常现象

**不支持各种歌单**：音乐平台的歌单、`.m3u` / `.pls` 这类歌单文件都不能导入；歌只能从你自己手机里的音频文件导入，导入之后可以在应用里自己建列表、往里加歌

**不采集、不上传**：没有账号、广告、统计；只有你自己点「保存歌词 / 歌词偏移」时才会有编辑操作，而且只针对歌词文件，不会对其它文件做任何操作

**不会删除音频**：写歌词、改歌曲的元数据都只改文件头部的标签区，音频数据一个字节都不变；在列表里添加歌曲、删除歌曲、删除列表都不会影响原始音频文件

**功能**：支持文件和文件夹目录导入（一次可勾选多个目录）、多列表管理、全局搜索、元数据就地编辑、五种播放模式、睡眠定时器、锁屏 / 通知栏 / 蓝牙控制、系统「媒体恢复」

**歌词来源**：同名 .lrc 歌词文件优先，其次内嵌

**界面**：悬浮卡片胶囊风格，深色主题，背景跟着当前歌曲封面自动变化

**要求**：Android 7.0 及以上；版本号 1.0，直接覆盖安装
