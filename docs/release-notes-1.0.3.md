# A-Music 1.0.3

这是一个**小修复版本**，功能和 1.0.2 一样。

## 修了什么

**从目录导入“系统媒体库还没索引”的音频文件时，列表里的时长显示 0:00。**

例如刚复制进手机、还没被系统扫描到的歌曲：播放器实际能读出 4:54，
但列表和数据库里存的是 0。现在导入时会从音频标签里补上时长；媒体库已有的时长仍然优先。

## 下载与安装

下载 `A-Music-1.0.3.apk`，在手机上点击安装（需允许“安装未知来源应用”）。
已经装过旧版本的可以直接覆盖安装，列表、设置和播放进度都不会丢。

## 说明

- 支持 Android 7.0（API 24）及以上
- 纯本地播放，不采集数据、没有账号和广告；唯一联网用途是你主动点「在线搜词」
- 不支持各种歌单（音乐平台歌单、`.m3u` / `.pls` 文件都不能导入）
- 其余功能说明见 1.0.2 / 1.0.1 / 1.0 的发布说明
