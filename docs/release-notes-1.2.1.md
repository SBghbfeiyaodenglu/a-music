# A-Music 1.2.1

这是一个**小修复版本**：播放中新增或替换的同名 `.lrc` 歌词文件，现在会自动被发现并加载。

## 改了什么

以前歌词只在切换歌曲时解析一次，而且歌曲目录的文件列表有缓存。所以：

- 播放一首歌时，如果当时没有 `.lrc`；
- 中途从电脑把 `歌名.lrc` 拷进这首歌的目录；
- 即使循环播放很多遍，也一直不显示歌词；
- 必须关掉 App 重新打开、重新播放才会读到。

现在播放中每 2 秒检查一次同名 `.lrc` 的状态：

- **新增**歌词文件 → 约 2 秒内自动解析并显示到歌词页；
- **替换/修改**歌词文件 → 自动重新读取新内容；
- **删除**歌词文件 → 自动回退到内嵌歌词；没有内嵌就显示无歌词。

检查只在 App 回到前台时进行，后台/锁屏时不会一直扫目录。打开歌词编辑、在线搜词或歌词偏移弹窗期间也会暂停检查，避免和正在编辑的内容互相覆盖。

## 下载与安装

下载 `A-Music-1.2.1.apk`，在手机/平板上点击安装（需允许“安装未知来源应用”）。
已经装过旧版本的可以直接覆盖安装，列表、设置和播放进度都不会丢。

## 说明

- 支持 Android 7.0（API 24）及以上
- 纯本地播放，不采集数据、没有账号和广告；唯一联网用途是你主动点「在线搜词」
- 不支持各种歌单（音乐平台歌单、`.m3u` / `.pls` 文件都不能导入）
- 其余功能说明见 1.2 / 1.1.2 / 1.1.1 / 1.1 / 1.0.3 / 1.0.2 / 1.0.1 / 1.0 的发布说明
