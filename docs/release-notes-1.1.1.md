# A-Music 1.1.1

这是一个**小修复版本**，功能和 1.1 一样，只收紧了歌词行距。

## 修了什么

**歌词每行之间的空隙太大（平板上尤其明显）。**

之前每行按“要容下两行文字”预留了 56~132dp 的最小高度，单行歌词上下会空出二三十 dp。
现在去掉了这个最小行高：

- 行高完全由歌词文字自己的行高决定，上下只留 2dp；
- 长句换行时这一行仍会自动长高，不会被截断；
- 歌词仍然是一行一句、纵向滚动；12 档字号不变。

## 下载与安装

下载 `A-Music-1.1.1.apk`，在手机上点击安装（需允许“安装未知来源应用”）。
已经装过旧版本的可以直接覆盖安装，列表、设置和播放进度都不会丢。

## 说明

- 支持 Android 7.0（API 24）及以上
- 纯本地播放，不采集数据、没有账号和广告；唯一联网用途是你主动点「在线搜词」
- 不支持各种歌单（音乐平台歌单、`.m3u` / `.pls` 文件都不能导入）
- 其余功能说明见 1.1 / 1.0.3 / 1.0.2 / 1.0.1 / 1.0 的发布说明
