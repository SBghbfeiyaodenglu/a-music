# A-Music 1.0.1

这是一个**小修复版本**，功能和 1.0 完全一样，只修了一个影响听感的问题。

## 修了什么

**播放歌曲时切换播放模式，歌会卡一下。**

以前每次切换“顺序循环 / 单曲循环 / 列表循环 / 随机循环”，应用都会把正在播放的
这首歌重新装载一遍，听起来会短暂中断一下。现在：

- 顺序 / 单曲 / 列表 / 随机 之间互相切换 —— **不再重建队列**，正在播的歌继续放，不会卡；
- 只有切换到或切出“倒序循环”时才会重建队列（倒序确实要把整个播放顺序反过来），
  这一步仍然会重新装载当前这首。

## 下载与安装

下载 `A-Music-1.0.1.apk`，在手机上点击安装（需允许“安装未知来源应用”）。
已经装过 1.0 的可以直接覆盖安装，列表、设置和播放进度都不会丢。

## 说明

- 支持 Android 7.0（API 24）及以上
- 纯本地播放，不采集数据、没有账号和广告；唯一联网用途是你主动点「在线搜词」
- 不支持各种歌单（音乐平台歌单、`.m3u` / `.pls` 文件都不能导入）
- 细节功能说明见 1.0 的发布说明
